# Cross-repository coordination

Own assignment, ordering, and result integration across multiple repositories. This does not apply to ordinary single-owner work or create authority to commit, deploy, transfer data, or invent an unrequested team.

- Assign each worker an owner and nonoverlapping paths; preserve existing and concurrent changes.
- Agree and verify the provider contract before connecting consumers. Do not label unverified consumers as passing.
- Use only host-supported delegation. Do not create user-owned chats for implementation subtasks; work sequentially if delegation is unavailable.
- Create a fresh `_workspace/<unique-run-id>/` only when saved handoff files are needed, and pass the exact path. Preserve other runs.
- Check optional checkout existence. Do not activate archived `toto` or add unrelated siblings.

When changing this skill, align triggers, scope, and returned evidence. Keep Claude compatibility paths linked to this directory. Distinguish static file checks from discovery and read-only invocation in a fresh Codex or Claude session.
